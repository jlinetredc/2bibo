# CONTENT.md

## General rules

Content should be:
- visual
- reusable
- age-appropriate
- culturally neutral enough for broad use unless intentionally localized
- simple to understand

## Theme packs

Preferred initial packs:

```text
Animals
Dinosaurs
Vehicles
Ocean
Space
Farm
Nature
Food
City
```

## Asset reuse

One animal image may be used in:
- Jigsaw
- Memory
- Sort
- Coloring
- Maze
- Bibo World

Avoid producing separate near-identical assets for every game.

## Audio

Use:
- gentle feedback sounds
- short contextual sounds
- optional narration
- no startling loud sounds

## Child instructions

Keep short.

Examples:

```text
Ghép hình.
Tìm đường về nhà.
Kéo hình vào đúng chỗ.
Chọn hình giống nhau.
```

## Science content

For games like Sink or Float, Magnet, Balance:

Do not make inaccurate scientific claims.

Curate real-world object properties intentionally.

## Asset loading

Prefer:
- optimized WebP/AVIF images
- SVG where appropriate
- lazy loading
- per-theme bundles

Do not preload all future game assets at app launch.
